# BBDesk v0.1.8

A patch update that makes Catalog easier to browse and keeps conversation completion visible until acknowledged.

## Changes

- Sort projects and applications alphabetically by their displayed names, using the interface language and ignoring letter case.
- Keep search results in the same alphabetical order.
- Preserve the saved order of connected projects and application shortcuts in their workspace panels.
- Retain a green completion check and time on the selected conversation until switching away. Background results stay green until selected and left. Split panes and Shared pool acknowledge only the active conversation, through pointer or keyboard focus.
- Replace completion indication with work status when another run starts. Errors, pending interactions and stopping retain their own states. Keep the last completion time in conversation tooltips after acknowledgement.

Completion acknowledgement is local to the mounted workspace. For observed running-to-idle transitions the timestamp records when the client observed completion; existing unread results use BB's latest-attention timestamp. Reloading the workspace resets this local history. BB's native read state is unchanged.

## Compatibility and installation

Existing configuration, RPC schemas and storage formats are unchanged. Package name `bb-plugin-dashboard` and plugin ID `dashboard` are retained. No settings reset is required.

Requires BB `>=0.48` and Plugin SDK `>=0.6.94 <0.7.0`. Experimental APIs are used; verification does not cover every host in this range.

Install this exact version with:

```sh
bb plugin install git:https://github.com/devalextelematika/BBDesk.git@v0.1.8
```

For an existing installation, use BB's update flow according to its configured source. An installation pinned to an earlier exact tag needs its source changed to receive this version.

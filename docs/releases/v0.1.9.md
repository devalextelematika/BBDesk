# BBDesk v0.1.9

## Changes

- Enable **Open applications in a BBDesk split** in **Catalog → More settings** to open app columns alongside the current chat. The preference, open app columns, order and widths are saved per browser. BB's native split remains the default and is available from the app column header.
- Drag an application's violet-tinted header to move its column. Resize columns by dragging a divider, pressing the arrow keys on it, or double-clicking it to equalize adjacent widths.
- Keep active and failed delegated work visible. When a selected worker finishes successfully, BBDesk opens its managing conversation if available. Independent forks keep their own status.

## Compatibility and installation

Package name `bb-plugin-dashboard` and plugin ID `dashboard` are retained. Requires BB `>=0.48` and Plugin SDK `>=0.6.94 <0.7.0`.

After the GitHub tag is published:

```sh
bb plugin install git:https://github.com/devalextelematika/BBDesk.git@v0.1.9
```

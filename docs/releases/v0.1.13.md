# BBDesk v0.1.13

Fixes provider quotas showing dashes when BB's usage cache is empty. BBDesk now discovers providers on connected sources and requests their quotas explicitly on each refresh. You can view available quotas directly in BBDesk without opening BB's Provider Usage panel first.

Requires BB `>=0.48` and Plugin SDK `>=0.6.94 <0.7.0`. Quota availability depends on BB's Provider Usage plugin and the provider's response.

To install this version after publication:

```sh
bb plugin install git:https://github.com/devalextelematika/BBDesk.git@v0.1.13
```

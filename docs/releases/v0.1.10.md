# BBDesk v0.1.10

Applications opened in a BBDesk split now show their navigation icon to the left of the title in the BBDesk column header. The embedded BB header and floating sidebar button are hidden so the application can use the space. The application's own controls remain available. When the application opens normally in BB, BB shows its usual header and sidebar button.

## Compatibility and installation

Requires BB `>=0.48` and Plugin SDK `>=0.6.94 <0.7.0`. Existing split layouts and preferences are retained.

After the GitHub tag is published:

```sh
bb plugin install git:https://github.com/devalextelematika/BBDesk.git@v0.1.10
```

## Verification

- A clean development install, TypeScript check, 208 automated tests and BB build passed. An independent production-only install and build passed with Zod as the sole production dependency.
- The installed header change was checked on ExpoGate. The column displayed the app icon to the left of its title, the embedded BB chrome was hidden, and ExpoGate's own navigation remained visible. The normal BB view still showed its header and sidebar control.

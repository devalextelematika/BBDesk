# BBDesk v0.1.12

A patch update from 0.1.11 with provider quotas, a new application layout and more reliable handling of failed conversations.

## Changes

- Show provider quota summaries in the application panel. Expand the dock for per-provider, machine and account details when available. The dock uses BB's provider usage plugin and reports unavailable or stale data; its visibility is controlled in Catalog → More settings and saved in this browser.
- Choose between BB's native split, BBDesk's resizable columns and a new accordion alongside chat in Catalog → More settings. The choice is saved in this browser, and the previous internal split preference is recognized.
- Allow explicitly hiding failed conversations, including matching background threads, until new activity needs attention. A failure no longer receives a successful-completion indicator.
- Improve application divider resizing, including pointer movement over embedded applications.

## Compatibility and installation

Requires BB `>=0.48` and Plugin SDK `>=0.6.94 <0.7.0`. Provider quota information depends on the availability and response of BB's provider usage plugin.

After publication, install this release:

```sh
bb plugin install git:https://github.com/devalextelematika/BBDesk.git@v0.1.12
```

# BBDesk v0.1.5

Work with several conversations side by side and arrange projects in the order you need. This release adds resizable conversation columns, saved layouts and clearer project and thread navigation.

## What's new

- **Side-by-side conversations:** Drag a bottom tab, an entry in More or a conversation from history onto the left or right half of a chat. Alt+Enter on a tab and Open alongside in history provide keyboard alternatives. Opening a conversation already in the layout focuses its existing column.
- **Resizable, remembered layouts:** Drag a divider or use Left/Right arrows (Shift for larger steps); double-click to equalize adjacent widths. The layout, active column and widths are saved in this browser per project. Columns have a minimum width of 320px and scroll horizontally when needed.
- **Active-column navigation:** Click or focus a column to activate it. Selecting another tab replaces only that column. The header X removes a column without hiding, archiving or stopping its thread. Conversations opened from history have temporary bottom tabs while present in the layout.
- **Project ordering:** Reorder selected projects in settings with drag handles, arrow keys or up/down buttons. Save applies the order across clients and reloads; Cancel discards draft changes. Existing project connection history is retained.
- **Provider icons:** Project tabs show one icon for each distinct agent provider among their open threads. Tooltips identify the provider and its conversations.

## Improvements

- Bottom conversation tabs appear newest first by creation time and keep their order through status changes. Hiding a tab selects its chronological neighbor; Undo retains the original position.
- Compact chat headings keep environment details in the tooltip.
- Split mode ignores invalid and cross-project drops, removes unavailable conversations and tolerates unavailable browser storage.
- The package name remains `bb-plugin-dashboard` and the plugin ID remains `dashboard`. Existing project, launcher and language preferences are preserved.

## Requirements and installation

Requires BB `>=0.48` and Plugin SDK `>=0.6.94 <0.7.0`. Experimental BB APIs are used; not every version in that range has been tested. Internet access is needed for dependencies and build tools on first installation. No external service or API key is required.

Install this exact release with:

```sh
bb plugin install git:https://github.com/devalextelematika/BBDesk.git@v0.1.5
```

For an existing installation, use BB's plugin update flow according to its configured source. An installation pinned to an older exact tag needs its source changed to receive this version.

## Verification

The release is checked with TypeScript, 96 automated tests, a clean development-dependency build and a clean production-dependency build. Tests cover split insertion, duplicate focus, active-column replacement, resizing, persistence, history, invalid drops, project ordering, provider icons and chronological tabs.

These checks use the SDK test harness and local builds. They do not establish live installed-UI behavior or compatibility with every supported BB version. No install, reload or live agent run is part of this release verification.

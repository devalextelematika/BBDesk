# BBDesk v0.1.11

A patch update from 0.1.10 that adds optional background-thread visibility rules and keeps project navigation on one row.

## Changes

- In Catalog → More settings, enable **Show background threads only when attention is needed** and enter title substrings, one per line. Matching ignores case and applies to threads created after activation in connected projects. Working matches remain in activity indicators without project tabs. Errors and input requests expose them until successful completion. Original BB threads remain available, and disabling the setting retains the substring list.
- Projects, Common threads and Shared pool share one navigation row. Entries that do not fit move into **More projects**, with keyboard navigation, thread creation, drag reordering and focus restoration. Switching through the menu preserves the mounted chat.
- Localize the message shown when a working conversation cannot be hidden.
- Show the provider in project chat headers, with the selected model and reasoning level when available from that chat's composer. Selection from another chat is not displayed.
- Consolidate workspace synchronization into one ordered pass and share storage, focus, drag and resize helpers. Simplify activity refresh scheduling and remove unused source, styles, icons and translations.
- Build against Plugin SDK 0.6.157 and verify the supported SDK floor in CI. Include the SDK RPC helper as a production dependency for Git installs and update third-party notices.

## Compatibility and installation

Requires BB `>=0.48` and Plugin SDK `>=0.6.94 <0.7.0`; the compatibility range is unchanged. Existing configuration and browser storage formats are retained. Background-thread rules are optional and disabled by default.

Install this release:

```sh
bb plugin install git:https://github.com/devalextelematika/BBDesk.git@v0.1.11
```

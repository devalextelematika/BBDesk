# BBDesk v0.1.7

A patch update to simplify workspace setup and improve conversation handling, activity refresh and mobile typing.

## Changes

- Connect projects and applications through a searchable Catalog with separate tabs and immediate checkbox changes. Connected entries are green; Common threads and Shared pool have their own controls. Reorder projects and applications in their panels.
- Hide conversation tabs immediately after a successful request, including in More, without the five-second Undo placeholder. Background completion preserves the current chat; a failed hide keeps its tab.
- Prevent thread creation when the Shared pool is full and preserve the draft. If the pool fills during creation, offer Open for the result. Late results respect newer navigation, explicit unpinning, disabling the pool and disconnecting the composing project.
- Return confirmed activity snapshots promptly and refresh in the background with coalescing, retries and cancellation guards. Saving settings remains successful if a later activity refresh fails. Only a complete successful full pass advances the full-sync timestamp and clears its error.
- Fit mobile chat to the visible viewport during keyboard input, temporarily hiding dashboard navigation and bottom tabs while retaining the native chat.
- Separate configuration, synchronization, workspace transitions and views; split automated tests into independent groups and remove unused UI dependencies. Zod remains the only production npm dependency.

## Compatibility and installation

Existing project, application and language settings, RPC schemas and storage formats are retained. Package name `bb-plugin-dashboard` and plugin ID `dashboard` are unchanged. No settings reset is required.

Requires BB `>=0.48` and Plugin SDK `>=0.6.94 <0.7.0`. Experimental APIs are used; verification does not cover every host in this range. First installation needs internet access for dependencies and build tools.

Install this exact version with:

```sh
bb plugin install git:https://github.com/devalextelematika/BBDesk.git@v0.1.7
```

For an existing installation, use BB's update flow according to its configured source. An installation pinned to an earlier exact tag needs its source changed to receive this version.

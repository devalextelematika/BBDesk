# BBDesk v0.1.4

BBDesk brings project conversations, live activity and application shortcuts into one BB workspace. This release adds interface language selection and makes it easier to find, switch and resume conversations.

## What's new

- **English and Russian interface:** English is the default. Select Russian in BBDesk's native plugin settings; the preference is shared across clients of the same server.
- **Search across project history:** Find conversations beyond the recent list by title or environment. Results appear in batches without closing the current chat while you search.
- **Conversation tabs:** Switch chats from the bottom tab bar, use overflow controls in narrow panes and undo hiding a tab for 12 seconds.
- **Resume project conversations:** Return to the last selected conversation when switching projects or reloading the same browser tab.
- **Remember permission mode:** New threads use the last mode successfully submitted through BBDesk in the same browser, subject to BB's provider and machine restrictions.
- **Native file previews:** Local file links in embedded chat open on the conversation's host, preserving line locations.

## Improvements

- Better keyboard focus handling and narrow-pane history navigation.
- Refined launcher behavior and conversation reading-position restoration.
- Existing project and application preferences are preserved. The package name remains `bb-plugin-dashboard` and the plugin ID remains `dashboard`.

## Requirements and installation

Requires BB `>=0.48` and Plugin SDK `>=0.6.94 <0.7.0`. The plugin uses experimental BB APIs; not every version in that range has been tested. Internet access is needed for dependencies and build tools on first installation. No external service or API key is required.

Install this exact release with:

```sh
bb plugin install git:https://github.com/devalextelematika/BBDesk.git@v0.1.4
```

For an existing installation, use BB's plugin update flow according to its configured source.

# BBDesk v0.1.6

Bring conversations from several projects into one shared workspace, or connect BB's personal conversations through Common threads.

## What's new

- **Shared pool:** Drag a conversation onto Shared pool or pin it from bottom tabs, More or history. Pinning leaves the current project open. Activate the pool to work with pinned conversations in resizable columns, each labeled with its project.
- **Saved arrangement:** Drag pool tabs before or after one another to reorder columns. Membership, order, the open view, active column and widths are remembered in this browser separately from project layouts. Removing a column only unpins the conversation.
- **Create in the pool:** Use its new-thread button to open BB's native composer and automatically pin the created conversation.
- **Optional pool:** Disable Shared pool in project settings without clearing its saved conversations. Pool visibility is shared by clients of the same BB server; its contents and layout remain browser-local.
- **Common threads:** Connect personal conversations outside projects through their own checkbox in project settings and access them from a separate tab.

Conversations from disconnected projects remain listed as unavailable until removed. Archived threads, threads hidden in BB and subagents are excluded from the pool. A conversation hidden only from BBDesk's project working set can still be pinned from history.

## Fixes and preservation

- Background hide completion respects the currently selected project and chat after navigation.
- Wrapped project tabs use the full width below the first row. Common threads, Shared pool and settings remain at the upper right; narrow workspaces retain a single horizontally scrolling row.
- The 100-project selection limit counts enabled projects while retaining disconnected project history.
- Existing project, launcher and language settings are preserved. The package remains `bb-plugin-dashboard`, with plugin ID `dashboard`.

## Requirements and installation

Requires BB `>=0.48` and Plugin SDK `>=0.6.94 <0.7.0`. Experimental BB APIs are used; not every version in that range has been tested. First installation needs internet access for dependencies and build tools. No external service or API key is required.

Install this exact release with:

```sh
bb plugin install git:https://github.com/devalextelematika/BBDesk.git@v0.1.6
```

For an existing installation, use BB's plugin update flow according to its configured source. An installation pinned to an older exact tag needs its source changed to receive this version.

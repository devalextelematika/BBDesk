# BBDesk

Your applications and current BB project work in one place.

Choose projects to follow, read and continue their threads inline, and start new tasks using BB's native chat and composer. Completed results stay until you hide them. Activity tracking continues while the dashboard is closed.

Configure application shortcuts on the left: open an app here or use its split button to open alongside (with BB's new-tab fallback). Project and launcher preferences are stored by this plugin; native BB sidebar settings are unaffected.

Use the BBDesk navigation provider (selected by Automatic when no other third-party navigation provider takes precedence). It preserves BB's original rail and supplies the launcher's live screens and native open actions. If a different navigation provider is pinned, select BBDesk under Settings → Appearance → Navigation. Your thread-list provider and saved navigation order/visibility remain independent.

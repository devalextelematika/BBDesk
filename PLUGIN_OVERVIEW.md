Keep ongoing conversations, project activity and application shortcuts within reach while working in BB.

## What you get

- Follow selected projects in your preferred order and see running work, completed results, requests for attention and agent provider icons.
- Read and continue conversations inline using BB's native chat and composer.
- Open conversations side by side from tabs or history, resize their columns and return to saved layouts in the same browser.
- Search project history beyond the recent list, switch conversations with bottom tabs and undo hiding a tab for 12 seconds.
- Return to the last selected conversation in each project during the same browser-tab session.
- Open application shortcuts in the workspace or alongside it using BB's native split action.
- Collapse and resize the application panel, with its layout remembered in your browser.
- Use English by default or select Russian in BBDesk's native plugin settings.

## How it works

Choose projects and application shortcuts in BBDesk. Project and shortcut preferences are shared across clients of the same BB server. The interface language is also shared; it changes BBDesk labels while user content and native BB controls retain their own language.

Drag project handles or use arrow controls in settings, then save their order. Drag a conversation into the workspace or use Open alongside to add a chat column. Split layouts and widths stay local to your browser. Closing a column leaves its thread available.

Activity tracking continues while BBDesk is closed. Completed results stay until hidden; fresh activity brings a hidden conversation back. Hiding a tab never archives or deletes its thread. Delegated agents appear through activity indicators without retaining completed subagent rows.

Select BBDesk under Settings → Appearance → Navigation if another navigation provider is pinned. The provider preserves BB's original rail and supplies the launcher's registered screens and native actions.

## Requirements

Requires BB >=0.48 and Plugin SDK >=0.6.94 <0.7.0. The plugin uses experimental BB APIs; not every host version in the declared range has been tested. First installation needs internet access for dependencies and build tools. No separate external service, account or API key is required.

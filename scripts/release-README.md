# BBDesk {{VERSION}}

Проекты, чаты и приложения BB в одном рабочем пространстве.

## Установка

Требуются BB {{BB_RANGE}} с Plugin SDK {{SDK_RANGE}}, Node.js 24 и npm.
Для установки зависимостей и инструментов сборки нужен интернет.

1. Распакуйте ZIP в постоянную папку.
2. Откройте терминал внутри папки `bb-plugin-dashboard` и выполните:

```sh
npm ci --include=dev
bb plugin install . --yes
```

BB должен быть запущен, команда `bb` должна быть доступна в терминале.
Не удаляйте и не перемещайте папку после установки: BB подключает локальный плагин по этому пути.

3. Откройте BBDesk в навигации BB. При необходимости выберите BBDesk в Settings → Appearance → Navigation.
4. Выберите свои проекты и настройте ярлыки приложений.

Внешние сервисы и API-ключи не нужны. В архиве исходники, готовая сборка dist, ресурсы и инструкция. Личная история, настройки, базы данных и ключи автора не включены. BB повторно собирает плагин при установке из локальной папки.

## Разработка

Проверка типов: `npm run typecheck`. Тесты: `npm test`. Сборка: `npm run build`.

Новый ZIP со ссылкой для скачивания: `npm run share:zip` внутри треда BB. Команда предназначена для Windows с PowerShell. Она использует текущие `BB_PROJECT_ID` и `BB_SERVER_URL`, собирает архив, загружает во вложения проекта и проверяет скачанные байты. Ссылка с localhost работает на компьютере с BB; другим людям отправляйте сам ZIP.
